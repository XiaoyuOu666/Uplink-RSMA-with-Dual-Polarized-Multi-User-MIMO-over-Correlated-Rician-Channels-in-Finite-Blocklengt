# Uplink RSMA with Dual-Polarized Multi-User MIMO

Python simulation code for the figures and numerical results presented in the paper:
**Uplink RSMA with Dual-Polarized Multi-User MIMO over Correlated Rician Channels in Finite Blocklength Regime**
